PLPE Game dialogue voice pack
=============================

Generated voice files are mapped 1:1 to public/audio/game/dialogue/manifest.json.
Folders:
- pl/ : Polish dialogue
- en/ : English dialogue

Voice roles:
- pepe: younger, quicker, energetic PolishPepe
- bocian: slower, lower mentor voice
- narrator: low, calm cinematic narration

The game uses dialogueVoice.ts to stop the previous line, duck background music,
and play the correct OGG file. Voice can be toggled in the prologue/story UI.
